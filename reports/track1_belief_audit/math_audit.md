# Mathematical audit of the Track 1 belief experiment

This is a post hoc diagnosis of the preserved experiment, not a new validation result. Existing source and experiment artifacts were not changed. Reproducible probes live in `work/track1_belief_audit/math_probes.py`; numeric evidence is in `math_probes.json` and `math_q_sweep_rows.json`. The audit used the existing 60 synthetic training seeds for parameter selection and inspected the already exposed 30 synthetic validation seeds. No real independent reference was added.

The central finding is that there is no evidence that the proposed mathematical program was comprehensively tested and refuted. Some mathematical components were numerically tested but never connected to the experiment; the connected observation pipeline had very little native support; and the synthetic comparison conflated state estimation, event detection and continuation. There are also important model assumptions that need to be corrected before a larger implementation.

## 1. Distinguish an unavailable estimand from a poor estimator

The observation model in `estimation.py:140-148` is effectively

\[
y_i=H x_i+L_i b_{g(i)}+\epsilon_i,\qquad b_g\sim N(0,I),\quad\epsilon_i\sim N(0,R_i).
\]

A shared constant bias and absolute object position are not separately observable from these measurements. For constant loading, the transformation

\[
p_i\mapsto p_i+c,\qquad Lb\mapsto Lb-c
\]

leaves every measurement unchanged. A prior can assign this ambiguity to position or bias, but it does not create evidence of physical location. The implemented initial negative position/bias covariance is mathematically appropriate for this ambiguity; the maintained covariance floor is a useful feature, not a defect.

The deterministic probe uses 100 identical observations `[20,-10]` with independent covariance `0.1 I` and shared covariance `400 I`. The filter returns `[20,-10]` with position marginal variances `400.012519` in each coordinate. Exactly the same observations are compatible with (A) a physical object at `[20,-10]` and zero bias or (B) an object at `[0,0]` and bias `[20,-10]`. More correlated observations cannot identify the correct world.

The stronger temporal ambiguity is between coherent physical motion and coherent tracking/camera drift. A 200 px/s common ramp has identical relative point agreement in both worlds. The small probe produces a 200 px/s estimated velocity and a process-jump event when coherence is supplied, even when the generating interpretation is a stationary object plus coherent tracking drift. This is an observational indistinguishability example, not evidence that every actual sequence has that failure.

Consequences:

- A robust aggregate of many anchors does not remove a shared systematic error. More points can reduce independent localization noise while leaving the common error unchanged.
- `coherence` is not independent evidence of physical acceleration. On native data it is the inlier fraction of the same similarity fit that produces the position; on synthetic data it is agreement among the same noisy points used for the median.
- Physical object motion needs additional information, such as reliable scene alignment, appearance-supported re-detection, material-point identity or external references. Until then the state must be described as a particular source/image-position estimand.
- The prior on shared bias should not be used to claim that hidden motion has been recovered.

## 2. The shared-error covariance is structurally narrow

The filter represents within-group cross-time error as

\[
\operatorname{Cov}(e_i,e_j)=L_iL_j^\top,
\]

where `L_i` is the principal square root of the supplied per-frame shared covariance (`estimation.py:159-162`). This is a coherent PSD construction, but every within-group shared trajectory is generated by only two latent Gaussian variables. It is not an arbitrary temporally correlated error process.

On native anchors, `anchors.py:190-192` supplies an isotropic seed-plus-deformation allowance and assigns its temporal dependence to the persistent seed group. That means deformation direction is represented as one persistent random direction with time-varying magnitude. Actual correspondence errors, camera errors, occlusion and deformation may change direction, have lag-dependent correlation, or change after re-detection. Static seed localization error under a changing similarity transform should be propagated by its actual Jacobian, rather than inferred from the marginal covariance's principal root.

A more defensible observation model separates terms with different causes:

\[
y_i=h(x_i)+J_i\delta_{\rm seed}+c_i+d_i+\epsilon_i,
\]

with explicit seed covariance, a scene/camera latent, a temporally correlated correspondence discrepancy and local localization noise. This decomposition must be identifiable or constrained by independent data; freely fitting all components to one scalar trajectory would merely redistribute the same residual. A low-order Gauss–Markov discrepancy or a small kernel/state-space basis is a candidate to test, not an established solution.

## 3. The adaptive update is an approximation, not a calibrated Bayesian switch

At `estimation.py:198-203`, the same residual first determines NIS, then selects a process-noise jump, then determines a Student-t-inspired measurement weight. When a jump is selected, measurement robustness is disabled (`weight=1`). The resulting Joseph update preserves PSD. That does not make its covariance an unconditional or selection-aware posterior.

For a genuine latent regime `r`, total posterior covariance is

\[
P=\sum_r w_r\bigl[P_r+(\mu_r-\bar\mu)(\mu_r-\bar\mu)^\top\bigr].
\]

Hard selection omits between-regime uncertainty. Data-dependent inflation/downweighting also changes the estimator's sampling distribution. The implementation already labels its output a conditional robust Gaussian approximation; that limitation must remain explicit. The incorrect step would be to interpret a finite PSD matrix or an acceptable aggregate NEES as physical calibration.

The proposed repair should distinguish measurement contamination, coherent model mismatch and sensor failure. A bounded latent-regime mixture, or a properly derived heavy-tailed state-space model with separate process and measurement scales, is more principled than interpreting every high coherent NIS as physical acceleration. But the regimes themselves remain unidentifiable in examples from section 1; the estimator must abstain or preserve multiple explanations when evidence cannot discriminate them.

## 4. The event comparison changes the event definition between estimators

For CV and Gaussian filters, `evaluate.py:63-65,84-86` marks threshold crossings of estimated speed. For the adaptive filter, `estimation.py:203` marks a high-NIS process jump while the estimated speed is above threshold. These are different detectors:

\[
E_{\rm speed}=1[\|\hat v_t\|\ge100,\ \|\hat v_{t-1}\|<100],
\]

\[
E_{\rm adaptive}=1[\mathrm{NIS}_t>\eta,\ \mathrm{coherent}_t,\ \|\hat v_t\|\ge100].
\]

The latter measures surprise under the selected process model, not motion onset alone. Increasing nominal process noise reduces NIS and can eliminate alarms even as velocity accuracy improves. This explains part of the trade-off seen in the training grid: at threshold 8, increasing `q` from 1,000 to 100,000 lowers velocity RMSE from 69.884 to 53.370 px/s while event recall falls from 0.967 to 0.267. It does not establish that a better motion state loses physical event information.

`event_score` then applies a 200 ms refractory rule, matches events inside a [-20,+250] ms window, and counts unmatched alarms only where true speed is below 5 px/s (`evaluate.py:127-145`). Unmatched alarms during ongoing movement are not false alarms under this metric. Repeated high-NIS alarms can therefore obtain onset recall without the same penalty they would receive in an event precision/recall evaluation. Quiet-minute false alarms remain useful, but do not replace all-alarm precision or duplicate-event accounting. Reversal events are not scored: only pickup/burst kinds produce reference onsets.

A fair next test must separate the state estimator from the detector: run an identical causal event head on every state, and separately compare innovation-based heads under identical definitions. Report all emitted events, one-to-one matching, missed events, duplicate/unmatched alarms, onset delay distribution and quiet-time exposure. Reversal and release need distinct reference definitions.

## 5. The synthetic design confounds motion duration, corruption and grouping

`synthetic.py:36-45` deterministically assigns:

| Corruption | Duration |
|---|---:|
| clean | 0.12 s |
| shared bias | 0.30 s |
| occlusion | 0.60 s |
| outlier | 0.12 s |
| missing interval | 0.30 s |
| camera | 0.60 s |

Noise level is also assigned by seed blocks. Therefore an observed corruption subgroup difference cannot be separated from duration/noise effects. The generated `participant` is `seed % 5`, which is exactly the motion kind (`synthetic.py:36,74`). Mean-participant RMSE is therefore mean-motion-family RMSE in this synthetic experiment, not a participant generalization statistic. It can be a deliberate macro-average, but must be named accordingly.

The anchor outlier corrupts one of sixteen points before a coordinatewise median (`synthetic.py:51-55`). This is a weak test of the downstream filter's gross-measurement robustness because the upstream aggregate has already rejected most of that disturbance. The synthetic filter also receives the true shared-bias group schedule and shared variance. That is useful for validating conditional inference under a known model, but optimistic compared with estimating such quantities from real RGB.

A valid stress design should independently randomize motion family, duration, amplitude, observation rate, independent noise, common drift, camera motion, visibility and correspondence failure. Include unseen combinations, not only new random seeds of tied combinations. Counterfactual pairs must hold latent motion fixed while changing corruption, and vice versa. Keep separate regimes with exactly specified likelihoods, where calibrated posterior checks are possible, and deliberately misspecified regimes, where robustness is measured without pretending the likelihood is correct.

## 6. Control estimators were not independently tuned

`select_synthetic` optimizes only the adaptive method (`evaluate.py:172-203`). The selected `q=1000` is then used by the Gaussian controls too (`evaluate.py:215-222`). That comparison is a shared-hyperparameter ablation, not an equally optimized comparison of estimator families.

The audit ran a separate training-only Gaussian sweep over `q ∈ {100,1000,10000,100000}`, preserving the original train/validation seeds. It removed auxiliary memory from these calculations solely to reduce cost; a direct parity check found maximum mean difference `2.49e-14` and covariance difference `2.27e-12`, consistent with the exact block-triangular model. It did not re-select the adaptive candidate.

Under the original scalar objective, independent Gaussian training selects `q=100`; dependent Gaussian training selects `q=10000` by a very narrow margin over `q=100000`. Neither becomes a convincing new winner on the exposed validation set. In particular:

| Dependent Gaussian q | Training continuation RMSE | Validation continuation RMSE | Validation velocity RMSE |
|---:|---:|---:|---:|
| 100 | 35.074 | 32.882 | 102.493 |
| 1,000 | 37.410 | 33.887 | 97.626 |
| 10,000 | 34.339 | 38.852 | 88.536 |
| 100,000 | 31.583 | 46.926 | 76.266 |

Units are pixels for continuation and pixels/second for velocity. Continuation here is square root of the mean per-episode MSE pooled across 250/500 ms, matching the training objective; these values must not be numerically substituted into the report's mean-motion-family/horizon-specific RMSE tables.

The strongest dependent Gaussian velocity result, 76.266 px/s, is close to the reported adaptive 75.875 px/s, but it has worse continuation. This supports a smoothing/reactivity and prediction trade-off, not a claim that one parameter change solves the task. The audit's extra grid point and already exposed validation make all these results diagnostic, not new validation evidence.

The fixed objective `RMSE + 20(1-recall) + 2 FAR` embeds a particular utility trade-off. It is not a mathematical definition of maximum performance. Report a Pareto frontier and choose application-relevant constraints before evaluation. Tune each family on the same training-only protocol and show both matched-support and coverage results.

## 7. Time quadrature is not a replacement for a measurement likelihood

`fit_history` uses

\[
W=D^{1/2}\Sigma^{-1}D^{1/2},\qquad
\hat\beta=(X^TWX+\Lambda)^{-1}X^TWy,
\]

where `D` contains normalized time masses (`estimation.py:87-91`). Its sandwich covariance is correct for the stated linear estimator. However, when the model is an exactly specified noisy cubic with known covariance, the Gaussian likelihood uses `Σ⁻¹`, not the extra time weights. Independent extra observations legitimately add information; correlated or duplicated observations should be handled through provenance and covariance rather than by erasing observation-density information.

The exact controlled probe uses 33 independent unit-variance observations: 30 timestamps in [0,0.15], then 0.4, 0.7 and 1.0 seconds. It fits a correctly specified cubic with zero regularization. Both fits are unbiased, and the coefficient covariance difference is PSD (minimum eigenvalue `3.12e-6`). Integrating prediction variance analytically over [0,1] gives:

- Ordinary GLS: `0.90465623`.
- Time-mass weighted fit: `1.37255565`.
- Variance ratio: **1.5172124**, or **51.7% higher**.

This is not a universal indictment of time quadrature. Time weights can define a desired approximation norm for compressing a known/noise-reduced trajectory when the cubic is misspecified. The error is conflating that approximation objective with statistically efficient latent-trajectory estimation.

The cleaner two-stage mathematical construction is:

1. Estimate the latent trajectory under a provenance-aware observation likelihood and explicit prior.
2. Project the posterior trajectory onto the bounded functional representation under the desired time/task norm.

For a linear posterior mean `m(t)` and basis `Φ(t)`, the deterministic projection is

\[
\beta^* = \left[\int\Phi^T G\Phi\,dt+\Lambda\right]^{-1}
\int\Phi^T G m(t)\,dt.
\]

Push the posterior covariance through that linear functional and keep approximation bias separate. This makes the meanings of observation information, representation budget, endpoint constraints and task distortion explicit. Exact endpoint constraints remain conditional on the endpoint estimand and its cross-covariance with the history.

Critically, `fit_history` is not called anywhere in the current experiment pipeline; its callers are tests. Its improved numerical contract did not cause either the reported synthetic gains or the native failure.

## 8. Memory cannot repair a misspecified process just by being appended

The implemented memories solve `dm_τ/dt=(p-m_τ)/τ`, with exact joint linear propagation. That is a sound linear-functional construction under the declared process. But under the same Markov CV model, the complete current filtering posterior over position, velocity and bias already determines the predictive distribution. Adding memories cannot improve the Bayes-optimal CV prediction under that model. They become useful for future behavior only if they expose missing regime variables or model mismatch and a different predictive model learns that relationship.

The memories are initialized at the first observed position (`estimation.py:183-189`). Their mean therefore contains an implicit constant prehistory term `exp(-t/τ) p_0`. At t=1 second and τ=2 seconds its coefficient is 0.6065. This is a defined initialization, not recovered two-second history. Any learned use of these descriptors needs history age/support and should compare against equal-budget recent observations.

The real auxiliary probe was correctly refused because training support was insufficient (`experiment.py:59-60`). Thus the experiment did not test whether memory helps downstream prediction. `fit_task_projection` is mathematically optimal only for affine rank-constrained reconstruction under a fixed SPD quadratic metric; that optimality does not transfer to arbitrary nonlinear downstream tasks or to a metric estimated unreliably from a tiny sample.

## 9. What is confirmed, and what remains a hypothesis

Confirmed by source and deterministic checks:

- Shared position/bias and coherent motion/drift have nonidentifiable cases.
- The correlated-error model has a restrictive two-dimensional within-group structure.
- Event definitions differ by estimator, and nonquiet unmatched alarms are not penalized by quiet FAR.
- Synthetic corruption/duration and motion-family/group labels are confounded.
- Adaptive-only tuning is not an equally tuned estimator comparison.
- Time-mass weighting can lose statistical efficiency even under the exact assumed cubic model; the provided counterexample is analytic.
- Several mathematical components are disconnected from the measured pipeline, and the memory learning stage did not train.

Not established by this audit:

- That a particular neural tracker will fix native support.
- That a specific mixture, GP, spline or memory architecture will outperform strong baselines on real independent labels.
- That the covariance construction, despite its limitations, caused the majority of observed real error.
- That the prior experiment falsified the full research program.

The next scientific sequence should therefore establish the estimands and observation support first, repair experimental identifiability and fairness second, and only then select a mathematical estimator or learned compression. A larger parameter search before those steps would produce more precise numbers for an ill-defined comparison.
