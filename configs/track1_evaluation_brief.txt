For your finalized Track 1 — Uncertainty-Aware Spatio-Temporal Functional Entity Encoding, evaluation must go substantially beyond segmentation IoU or reconstruction loss.

Track 1 is responsible for transforming video frames into a geometrically meaningful, temporally smooth, uncertainty-aware functional representation that Tracks 2–4 can trust.

I recommend evaluating it across 12 metric families, covering the entire path from frame alignment to the final `FunctionalEntityState`.

One important distinction: the ideal mathematical value and a realistic acceptance threshold are not the same thing. For example, zero trajectory error is ideal, but a practical threshold depends on image resolution, object scale, annotation quality, visibility, and camera calibration.

The numerical targets below are therefore proposed engineering gates for your pilot, not published EPIC-KITCHENS/VISOR benchmark standards. They should be calibrated against a carefully reviewed, manually annotated validation subset.

A critical failure mode is overstabilization: the background becomes perfectly stationary because the model has also suppressed meaningful object movement.

Therefore, background reprojection error must be paired with foreground motion preservation.

### Family D — Periodic cubic B-spline reconstruction

Your boundary is represented by

\\[ \gamma_f(u)=\sum\_{m=0}^{M-1}P\_{f,m}B_m(u). \\]

The fitted curve should approximate the observed silhouette while remaining stable and geometrically valid.

| Metric                            | Meaning                                                            | Ideal / proposed target                     |
| --------------------------------- | ------------------------------------------------------------------ | ------------------------------------------- |
| Spline-to-contour Chamfer         | Fitted spline versus observed contour                              | 0; ≤ 1–2% object scale                      |

| Normal-direction residual         | Error projected onto boundary normal                               | 0; ≤ 1–2% object scale                      |
| Tangential residual               | Error projected onto boundary tangent                              | 0; interpret carefully                      |
| Closure error                     | \\(\\\|\gamma(0)-\gamma(1)\\\|\\)                                  | Numerical zero                              |
| Periodic derivative mismatch      | Difference in derivatives at seam                                  | Numerical zero through required order       |
| Self-intersection rate            | Fraction of simple-object contours with invalid crossings          | 0                                           |
| Orientation consistency           | Fraction retaining expected clockwise/counterclockwise orientation | 100%                                        |
| Curvature error                   | Difference in contour curvature at matched locations               | 0; noise-sensitive                          |
| Curvature roughness               | Integral of squared curvature or appropriate regularizer           | Controlled, not necessarily minimized       |
| Control-point stability           | Sensitivity of control points to small annotation perturbations    | Low                                         |

Important: if closure and derivative continuity are enforced by the periodic basis, these are primarily implementation invariants, not learned performance achievements.

A visually smooth contour is not necessarily accurate. Over-regularization may erase fingers, handles, narrow protrusions, and contact-relevant geometry.

### Family F — Uncertainty ribbons and covariance calibration

This is one of the most important differentiators of your Track 1.

For a predicted boundary point \\(\hat p\\), normal vector \\(n\\), and point covariance \\(\Sigma_p\\),

\\[ \sigma_n^2=n^\top\Sigma_p n. \\]

The ribbon should represent actual geometric uncertainty, not merely produce visually plausible confidence bands.

| Metric                         | Meaning                                                                  | Ideal / proposed target                   |
| ------------------------------ | ------------------------------------------------------------------------ | ----------------------------------------- |
| 50% interval coverage          | Fraction of true normal displacements inside predicted 50% interval      | 50%                                       |
| 90% interval coverage          | Fraction inside predicted 90% interval                                   | 90%                                       |
| 95% interval coverage          | Fraction inside predicted 95% interval                                   | 95%                                       |
| Coverage deviation             | \\(\lvert\text{observed coverage}-\text{nominal}\rvert\\)                | 0; ≤ 3–5 percentage points initially      |
| Mean interval width            | Average uncertainty ribbon width                                         | As narrow as possible at correct coverage |
| Interval score                 | Proper scoring rule balancing width and missed coverage                  | Minimize                                  |
| Gaussian NLL                   | Negative log-likelihood of reference observations                        | Minimize on held-out data                 |
| Mahalanobis consistency        | Whether squared normalized errors match their assumed distribution       | Match reference distribution              |
| Covariance PSD violations      | Fraction with negative covariance eigenvalues beyond tolerance           | 0                                         |
| Covariance conditioning        | Ratio of largest to smallest eigenvalue                                  | Finite; avoid numerical instability       |
| Error–uncertainty correlation  | Whether larger predicted uncertainty corresponds to larger actual errors | Positive; assess ranking and calibration  |
| Risk–coverage AUC              | Error remaining when high-uncertainty predictions are rejected           | Minimize                                  |
| Occlusion uncertainty response | Whether uncertainty increases appropriately under occlusion              | Positive response, calibrated             |
| Uncertainty sharpness          | Mean predictive dispersion at fixed calibration                          | Minimize                                  |

The best uncertainty model is not the one producing the narrowest ribbons. It is the one that achieves the claimed coverage with the narrowest defensible intervals.

For correlated contour points, pointwise 95% coverage does not imply that the entire contour lies inside its ribbon 95% of the time. If you need whole-contour guarantees, evaluate simultaneous coverage separately.

### Family H — Temporal Legendre projection quality

Your finalized temporal representation uses degree-3 Legendre polynomials over 1-second windows with 0.25-second hops:

\\[ \hat h_k(t)=\sum\_{j=0}^{3}C\_{k,j}L_j(\tau_k(t)). \\]

This is arguably the most important family for deciding whether Track 1 is ready for Track 2.

| Metric                                        | Meaning                                                         | Ideal / proposed target                         |
| --------------------------------------------- | --------------------------------------------------------------- | ----------------------------------------------- |
| Temporal reconstruction RMSE                  | Error between observed state and polynomial reconstruction      | 0; normalize by feature scale                   |
| Temporal reconstruction \\(R^2\\)             | Explained temporal variance                                     | 1; ≥ 0.95 on well-observed, nonconstant windows |
| Endpoint position error                       | \\(\\\|\hat h_k(t_k^{end})-h(t_k^{end})\\\|\\)                  | 0; ≤ 3% frame diagonal for position             |
| Endpoint velocity error                       | Difference between polynomial derivative and reference velocity | 0; ≤ 5–10% reference motion scale               |
| Endpoint acceleration error                   | Second derivative versus smoothed reference acceleration        | 0; establish empirical threshold                |
| Temporal fit NLL                              | Likelihood under propagated fitting uncertainty                 | Minimize                                        |
| Normalized residual consistency               | Whitened residual distribution                                  | Match assumed noise distribution                |
| Polynomial coefficient covariance calibration | Empirical coefficient errors versus estimated covariance        | Correct nominal coverage                        |
| Window validity rate                          | Fraction of eligible windows producing reliable coefficients    | ≥ 90% initial gate                              |
| Sparse-window degradation                     | Error versus number of valid observations                       | Graceful degradation                            |
| Occlusion robustness                          | Error versus occluded fraction of the window                    | Controlled and calibrated                       |
| High-frequency residual energy                | Motion energy not represented by cubic projection               | Monitor against actual motion                   |
| Numerical conditioning                        | Conditioning of weighted design matrix                          | Stable; no catastrophic tail                    |
| Robust-outlier sensitivity                    | Effect of corrupted frames on fitted coefficients               | Low                                             |

For the position endpoint,

\\[ \hat h_k^{end}=\phi(1)^\top C_k. \\]

For the velocity endpoint, because the physical window lasts one second,

\\[ \hat{\dot h}\_k^{end}=2\phi'(1)^\top C_k. \\]

The derivative is therefore with respect to physical time, not merely normalized Legendre time.

A crucial qualification: high \\(R^2\\) on the frames used for fitting does not prove generalization. Also report reconstruction on held-out observations inside a window, and endpoint extrapolation errors over short future intervals where appropriate.

### Family I — Overlapping-window consistency and temporal continuity

Since adjacent windows overlap by 75%, the same physical time is represented by multiple Legendre polynomials.

For two overlapping windows \\(k\\) and \\(k+1\\), compare their predictions at the same physical timestamp \\(t\\):

\\[ d\_{k,k+1}(t)=\hat h_k(t)-\hat h\_{k+1}(t). \\]

| Metric                         | Meaning                                                          | Ideal / proposed target         |
| ------------------------------ | ---------------------------------------------------------------- | ------------------------------- |
| Overlap position disagreement  | RMS difference of overlapping-window predictions                 | 0; within predicted uncertainty |
| Overlap velocity disagreement  | RMS difference of derivatives at identical timestamps            | 0; within predicted uncertainty |
| Overlap covariance consistency | Whether differences agree with joint predictive covariance       | Calibrated                      |
| Boundary jump magnitude        | Position discontinuity at representation handoffs                | 0                               |
| Derivative jump magnitude      | Velocity discontinuity at handoffs                               | 0                               |
| Temporal jitter index          | High-frequency fluctuations not supported by observations        | Low                             |
| Static-object drift            | Spurious temporal motion for stationary objects                  | Approximately 0                 |
| Fast-event retention           | Fraction of brief annotated movements retained in representation | High                            |
| Motion onset timing error      | Delay between annotated motion onset and detected change         | 0; ≤ 0.25 s as an initial gate  |
| Motion offset timing error     | Delay at motion cessation                                        | 0; ≤ 0.25 s                     |

Important mathematical caveat: overlapping-window estimates are correlated because they share frames. Their covariance cannot generally be added as though they were independent.

Also, continuity is desirable but not absolute: a real collision, abrupt grasp, or fast hand movement can produce a genuine change in velocity. A metric that rewards excessive smoothing may harm downstream event recognition.

## 3. How to evaluate the statistical validity of your uncertainty

A good diagnostic for multivariate estimates is the normalized estimation error squared (NEES):

\\[ \operatorname{NEES}\_k = (\hat x_k-x_k^{GT})^\top \Sigma_k^{-1} (\hat x_k-x_k^{GT}). \\]

For a correctly specified Gaussian model with \\(d\\) evaluated dimensions and independent reference truth, the expected NEES is approximately \\(d\\).

Expected mean NEES ≈ 2 for a calibrated 2D Gaussian position estimate. Higher values suggest underestimated uncertainty; lower values suggest overly broad covariance, assuming the estimator and reference model are otherwise valid.

For a 2D position vector, approximately 95% of individual squared Mahalanobis errors should lie below the \\(\chi^2_2\\) 95th-percentile threshold, about 5.99.

However, reference annotation uncertainty must be included when it is non-negligible. Evaluating against noisy polygons as if they were exact truth can make a properly calibrated estimator appear miscalibrated.

For temporal coefficients, use the relevant coefficient covariance and degrees of freedom, and avoid treating overlapping windows as independent observations when constructing confidence intervals.

## 6. Four ablations that I consider essential

Before freezing Track 1 outputs for Koopman training, run these controlled comparisons:

| Ablation                                             | What it establishes                                                                   | Primary metrics                                    |
| ---------------------------------------------------- | ------------------------------------------------------------------------------------- | -------------------------------------------------- |
| Uniform vs confidence-weighted Legendre fitting      | Whether covariance-aware weighting improves reconstruction and robustness             | Held-out RMSE, endpoint error, NLL                 |
| Direct contours vs B-spline + wavelet representation | Whether the functional shape representation preserves important details efficiently   | Boundary F-score, compression, small-feature error |
| Raw image coordinates vs canonicalized coordinates   | Whether camera compensation removes nuisance motion without suppressing real movement | Static drift, foreground motion error              |
| Point estimates vs propagated uncertainty            | Whether uncertainty improves reliability and selective prediction                     | Coverage, NLL, risk–coverage AUC                   |

For the weighted-fitting ablation, compare methods on identical observation sets and use the same temporal windows. For the representation ablation, compare under matched memory or feature-dimensionality budgets where possible.

## 7. Final recommendation: which metrics matter most?

For your architecture, I would prioritize these five above all others:

1. Held-out endpoint position and velocity error — because these are the immediate physical quantities consumed by the dynamical model.
2. Uncertainty calibration — because Track 2 prediction errors and Track 3 contact reasoning depend on knowing when Track 1 is unreliable.
3. Boundary accuracy, especially near contacts — because a small contour error near a fingertip or object handle can change the inferred interaction.
4. Overlapping-window consistency — because Track 2 receives a 4 Hz state stream derived from highly overlapping windows.
5. Participant-held-out generalization — because strong within-video reconstruction does not establish that the representation works on unseen subjects and environments.

The decisive Track 1 success criterion is not merely reconstructing the input accurately. It is producing a stable, calibrated, physically interpretable state stream that preserves the motion and geometry needed for downstream dynamical and relational reasoning.

I would also retain a small manually verified, high-frame-rate reference set for endpoint velocity, short events, and contact-boundary evaluation. With 1-second cubic fitting and 0.25-second output hops, some fast movements can be smoothed or aliased; that limitation cannot be detected reliably using only reconstruction metrics computed from the same low-frequency representation.
